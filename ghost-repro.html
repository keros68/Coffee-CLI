Coffee CLI terminal ghosting — standalone repro

Reproduces issues #47 / #74 without a Coffee build, using the renderer Coffee ships: @xterm/xterm 6.0.0 + @xterm/addon-webgl 0.19.0, pinned, from jsDelivr, with TierTerminal's options. Open it in any Chromium browser — no server needed, but it has to be the visible tab, since Chrome does not render a hidden one.

Each run streams 8 changing TUI frames into a terminal while its wrapper is masked with opacity: 0 — what TierTerminal does for 150 ms on tab switch-back and 180 ms on window foreground — then refreshes and unmasks. Lit pixels in the WebGL drawing buffer are counted with readPixels from inside xterm's render callback, so a frame is measured before the compositor ever sees it. A correct result is 1.0×: the revealed frame holds one frame's worth of text.
